HTTP Security Headers Evaluation

An automated header security assessment conducted via Snyk Security Headers assigned the target a **D Grade**. While HTTP Strict Transport Security (HSTS) is enabled, multiple critical browser security controls are missing.

Header Name Status Risk Level Security Impact
Strict-Transport-Security PRESENT LOW Forces HTTPS connections and prevents SSL stripping attacks.
Content-Security-Policy MISSING HIGH Exposes site to Cross-Site Scripting (XSS) and data injection attacks.
X-Frame-Options MISSING MEDIUM Allows embedding in framing/iframes, enabling Clickjacking attacks.
X-Content-Type-Options MISSING MEDIUM Allows browsers to MIME-sniff response payloads away from declared content type.
Referrer-Policy MISSING LOW-MED May leak sensitive URL query parameters to third-party domains.
Permissions-Policy MISSING LOW Does not restrict browser feature capabilities (camera, microphone, geolocation).
